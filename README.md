Sales Performance Dashboard

Project Overview

An interactive Power BI dashboard for analyzing sales, profit, order count, and regional performance.

Tools Used

- Power BI
- DAX
- Microsoft Excel

Dashboard Features

- Sales, Profit, Total Cost, and Order Count KPIs
- Top 10 Products by Sales
- Sales by Category and Region
- Profit by Category
- Monthly Sales Trends
- Region and Category Filters

Skills

Data Analysis | Data Visualization | Power BI | DAX
